# Project Title: Motor Trader

## Project Overview
This web application is a platform designed to guide novice drivers through the complexities of vehicle ownership and trading. This project aims to address challenges such as buying, selling and insuring a vehicle which can become overwhelming for first time drivers.

The primary goal of the web application is to ensure cohesive user experience and simplify the user journey. The platform focuses heavily on clean user interface (UI) design, intuitive layout and navigation, as well as secure back-end input validations to ensure a reliable experience.

## Collaboration & Team Responsibilities
This project was a collaborative team assignment at university to portray a real-world development environment.
 - **My Responsibilities:** I developed the front-end responsive design, back-end functionality, and local database connectivity. I specifically focused on engineering the dynamic search bar and user authentication system, testing locally using XAMPP. Whilst also assisting with troubleshooting, and the technical documentation.
 - **Team Member Responsibilities:** My classmates focused on the core responsive front-end layouts, CSS styling and JavaScript interactivity, compiling the content for webpages, additional back-end functionality and primary database integration.  

## Tech Tools
 - **Front-end:** Responsive and interactive web (HTML, CSS, JavaScript).
 - **Back-end:** Server-side logic for routing (PHP).
 - **Database:** Data management for storing user details, vehicle specifications and insurances  (MySQL + XAMPP Apache web server for local testing).
 - **Development Environment:** Collaborative environment for sharing files (GitHub).

 ## Key Feature
 - **User Authentication:** A login system that authenticates user credentials against the database, allowing registered user to access personalised dashboard.
 - **Dynamic Search Bar:** A search field that allows users to search for vehicles - tested locally via XAMPP.
 - **Insurance Quote:** A form system that captures user and vehicle data, to calculate and display personalised insurance breakdown.
 - **Interactive Selling & Purchasing:** A multi-page layout that helps a new driver with selling or purchasing a vehicle.
